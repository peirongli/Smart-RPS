🧠 石头剪刀布心理博弈

⚠️ 重要提示

由于浏览器安全限制，此游戏需要通过本地服务器运行。

🚀 启动方法：

  1. Python 用户：
    在此文件夹中打开终端，运行：
    python -m http.server 8000
    然后访问：http://localhost:8000
  2. Node.js 用户：
    运行：npx serve .
    然后访问显示的地址
  3. VS Code 用户：
    安装 Live Server 扩展
    右键 index.html → Open with Live Server
  4. PHP 用户：
    运行：php -S localhost:8000
    然后访问：http://localhost:8000

📋 准备工作：

1. 获取 DeveloperWorks API 密钥

2. 在 config.js 中填入配置（推荐）

3. 启动本地服务器

4. 开始游戏
