## 1. 现状诊断

### 1.1 AI 的"读心"能力并未实现（最严重）

`ai.js:76-84` 提示词宣称分析玩家偏差规律、保持 70/30 策略性；`README.md:12` 宣称"会分析你宣告 vs 实际的偏差规律"。

实际实现：
- `getAiMove()`（`ai.js:233`）每轮发起**全新**的 `system + user` 两消息请求，无对话记忆。
- `buildContextMessage()`（`game.js:146`）只把**最近 3 轮**的结果塞成散文摘要。
- 无胜率统计、无出拳频率分布、无条件模式推理。

后果：第 20 轮的 AI 与第 1 轮能力完全相同。玩家的伪装、设套、误导在 10 轮内就会被识破为无用——因为对手真的什么都没学到。

### 1.2 博弈结构已单方面塌陷

时序（`game.js` 头部注释声明的防作弊时序）：

```
玩家宣告 → AI 回应并锁定 actual → 玩家出 actual → 同步揭晓
```

AI 的 `actual` 在 `game.js:126` 就锁定，之后无法更改，**防作弊成立**。但玩家在 `handleAction`（`game.js:163`）出拳前，AI 的宣告已经渲染在 `ui.js:127` 的聊天流里。

于是玩家的最优策略退化为：**读 AI 宣告 → 反制**。AI 无法应对。

> 这是玩家单方面透明的作弊。谁先发现，谁赢麻了。而游戏内没有任何机制阻止它。

### 1.3 解析失败被静默伪装成"AI 保密"

```js
const declared = extractDeclared(raw) || 'secret';   // ai.js:250
```

`extractDeclared` 靠中文关键词匹配（`宣告出/倾向出/打算出/可能出/想出/选择出`，`ai.js:179`）。模型若说"我这轮押布"，匹配失败 → 返回 `null` → 静默变成 `secret`。

后果：历史记录里 AI 显示"不告诉你"，而 AI 实际有宣告。本该存在的博弈信息凭空消失，且**双方都不知道这是个错误**。在 P1 的双盲机制下这尤其致命——宣告是唯一的博弈素材。

### 1.4 XSS 注入

`ui.js:125` 对 AI 返回文本只做 `\n → <br>` 替换就交给 `innerHTML`。AI 若返回 `<img src=x onerror=...>` 会直接执行。

AI 输出是不可信输入。项目把"无后端、代码可审查"当卖点（`README.md:41-42`），这里应有 `textContent` + CSS `white-space: pre-wrap`。

### 1.5 失败轮次留下误导状态

`handleDeclare` 失败时调 `backToDeclare()`（`game.js:133`），但玩家的宣告已经写进聊天流（`game.js:121`）。玩家看到两条宣告、只结算一条。

## 3. P1：结构化输出 + 双盲承诺

### 3.1 为什么先改结构化输出

现在 `ai.js` 用"正则从自由文本里抠出宣告和实际出拳"。这导致：
- 解析脆弱（1.3）
- 无法携带"AI 的推理"这类新字段
- 宣告与实际出拳混在同一段文本里，只能靠 `declarationOnly()`（`ai.js:206`）裁剪后**在玩家眼前展示剩余部分**——这正是信息泄漏的根源

改成模型直接输出三个独立字段，一次性解决以上全部。

### 3.2 新的模型输出契约

提示词要求模型输出 JSON：

```json
{
  "taunt": "你最近三次都说要出石头，结果都出了布——这次我信你才怪。",
  "declared": "rock | paper | scissors | secret",
  "actual": "rock | paper | scissors"
}
```

- `taunt`：心理战台词，**立即显示**给玩家。这才是 AI 的人格所在。
- `declared`：宣告，**锁到揭晓时才显示**。
- `actual`：实际出拳，永不在揭晓前泄漏。

解析：优先 `JSON.parse`（剥 ```json 围栏），失败则回退现有正则兜底，再失败则按 1.3 处理。

> 兼容性：`response_format: {type:'json_object'}` 在 DeepSeek / 智谱上支持不一，因此**不依赖该参数**，改为提示词约束 + 宽松解析。可选开启时作为增强。

### 3.3 双盲承诺的新时序

```
① 玩家宣告（可见给 AI）
② AI 输出：taunt 立即显示；declared + actual 锁住，两个都不显示
③ 玩家出实际拳（此时不知道 AI 宣告）
④ 同步揭晓：双方宣告 + 实际出拳一起亮
```

改动点：

| 文件 | 改动 |
|---|---|
| `ai.js:206` `declarationOnly()` | 删除（不再需要裁剪）。改为返回 `{taunt, declared, actual, raw}` |
| `ai.js:250` | 不再 `\|\| 'secret'`，按 1.3 处理 |
| `game.js:124-129` | `aiDeclared`/`aiActual` 照旧存 state；聊天流只发 `taunt` |
| `game.js:167` | 揭晓前加一句提示，制造张力："AI 也在看着你的实际出拳" |
| `ui.js:170-185` `renderResult()` | 已有 `#ai-declared` 槽位，无需改结构 |
| `index.html` | 加一行"宣告已锁定，揭晓时揭晓"的视觉提示 |
| `ai.js:43` `SYSTEM_PROMPT` | 重写为 JSON 契约 + 新时序说明 |

**防作弊时序完全不变**：AI 仍在玩家宣告后的那一次调用里锁定 actual，且新增的 `declared` 字段同样在锁定瞬间产生，不构成额外泄漏。

### 3.4 A/B 方案取舍

在动手前明确否决项，避免做一半再讨论：

| 方案 | 描述 | 结论 |
|---|---|---|
| **A1 隐藏 AI 宣告**（推荐） | AI 宣告锁到揭晓；taunt 仍可见 | ✅ 博弈对称，玩家靠推测应对 |
| A2 双方同时宣告 | 玩家宣告也延迟 | ❌ 玩家失去主动权，且违背"先承诺后揭晓"的设计初衷 |
| A3 保留宣告可见 | 现状 | ❌ 已论证被单方面利用 |

### 3.5 预期效果

玩家从"读宣告 → 反制"变成：
> "AI 说它要出石头。它在说真话吗？我要不要反着出？"

这才是"心理博弈"。且**AI 的谎言现在有代价也有意义**——因为玩家不再能直接读它。

## 4. P2：博弈画像 + 难度分级

### 4.1 博弈画像（让 AI 真的会读你）

新增 `eval/profile.js`（或直接放 `game.js` 内的纯函数）：

```js
buildProfile(history) → {
  actualDist:      { rock, paper, scissors },   // 实际出拳频率
  deceiveRate:     0.66,                        // 宣告≠实际的比例
  secretRate:      0.13,
  secretPatterns:  [{ declared:'rock', actual:'paper', p:0.8, n:5 }],
  recentTrend:     [win, lose, draw, ...],      // 近 10 轮
  actualByDeclare: { rock: { paper: 3, scissors: 1 } }
}
```

`secretPatterns` 是最有价值的字段：**"你宣告石头时 80% 实际出布"** —— 这正是提示词里承诺却没实现的"偏差规律"。

注入方式：拼成简短文本块追加到 user 消息，而非塞进 system（system 保持通用人格不变）。

### 4.2 难度分级（人格）

| 难度 | 行为 | 适合 |
|---|---|---|
| 新手 | 80% 宣告=实际，不利用画像 | 熟悉规则 |
| 老手 | 利用画像反制，30% 随机 | 默认 |
| 读心者 | **显式在 taunt 里引用画像结论** | 想要烧脑 |

关键设计：**让 AI 的"读心"可见**。

> "你最近三次宣告石头都出了布，这次我不信了。"

这一句话就把博弈从"暗中较劲"变成"明确的心理对抗"，玩家会产生"我要反制"的动力。这是可玩性的核心回路——比加更多功能都有效。

> 注意：这里刻意保留矛盾（嘴上说不信，实际仍按最可能出布），镜像玩家在 P1 中也能玩的"说谎"。

### 4.3 难度自适应（防劝退）

老手/读心者可能让玩家连败。建议：
- 连败 3 轮后，在 taunt 里给一次提示（"运气而已，别气～"），不改数值。
- 暂不做数值自动降级——那会让玩家察觉被"照顾"，反而廉价。
