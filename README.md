# Smart Rock-Paper-Scissors

和会读你行为模式的 AI 玩石头剪刀布——但规则改了：**每轮先宣告、后出拳**，宣告可以撒谎，也可以选择"不告诉你"。输赢只看实际出拳。

## 玩法

1. **宣告阶段**：你先说要出什么（可以虚晃一枪，或者保密）
2. **AI 回应**：AI 说出它的计划（它也会骗你）
3. **实际出拳**：选你真正要出的
4. **同步揭晓**：按双方实际出拳判定胜负

AI 会分析你"宣告 vs 实际"的偏差规律、记住最近几轮对局、调整策略，赢了还有表情包嘲讽。

## 本地运行

游戏是零构建的纯静态站，任意静态服务器即可：

```bash
python3 -m http.server 8000
# 或 npx serve .
```

打开 `http://localhost:8000`，首次进入需要配置模型接入（见下）。

## 模型接入（自带 API key）

游戏不再绑定任何游戏平台 SDK，直接调用 **OpenAI 兼容的 `/chat/completions`** 接口。开始界面选择服务商即可，已内置预设：

| 服务商 | 默认模型 |
|---|---|
| DeepSeek | deepseek-chat |
| OpenAI | gpt-4o-mini |
| 智谱 GLM | glm-4-flash |
| Moonshot Kimi | moonshot-v1-8k |
| 自定义 | 任意 OpenAI 兼容端点（含本地 Ollama） |

预设只带出 base URL 和默认模型名，两者都可手改。

**关于你的 API key**：

- key 只保存在你浏览器的 localStorage，请求由浏览器**直连**你选择的服务商，不经过任何中间服务器
- 游戏没有后端，代码里没有任何上报逻辑，欢迎审查 `ai.js`（全部网络请求只有一处）
- 注意各家服务商对浏览器直连（CORS）的支持不同，DeepSeek / OpenAI / 智谱 / Moonshot 均已支持
- 不建议在公共电脑上使用

## 设计说明

**防作弊由调用时序保证，不靠 prompt 自觉。** AI 的实际出拳在你宣告后的那次模型调用里就已经锁定（游戏每轮只调一次模型），之后你出什么它都改不了——结构上不存在 AI 偷看的可能。这条时序写在 `game.js` 头部注释里，改动前请想清楚。

**AI 回应格式异常时，绝不替 AI 出拳。** 系统从回应里解析"我实际出：石头/布/剪刀"；解析失败会自动重问一次，仍失败则明确报错、本轮作废——不会随机替 AI 出一个拳然后让玩家莫名其妙。

**对局记录持久化。** 比分和历史存在 localStorage，刷新不丢；"重新开局"一键清零。

## 本地开发

想改代码但不想花 token？仓库带了一个本地 mock：

```bash
node dev/mock-server.mjs   # 启动在 http://localhost:8768/v1
```

游戏设置里选"自定义"，base URL 填 `http://localhost:8768/v1`，key 和模型随便填即可玩通全流程。模型名填 `bad-model` 会返回无法解析的回应，用来测试报错路径。

## 项目结构

```
├── index.html          # 页面结构与设置界面
├── styles.css          # 样式
├── ai.js               # 模型接入：fetch 客户端、系统提示词、回应解析
├── game.js             # 状态机、规则、持久化、表情包彩蛋
├── ui.js               # DOM 渲染与事件绑定
├── images/             # 出拳图与表情包素材
└── dev/mock-server.mjs # 本地 mock（测试用，不参与运行）
```
