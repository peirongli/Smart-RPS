# 🧠 石头剪刀布心理博弈游戏

一个基于 DeveloperWorks SDK 的创新猜拳游戏，融合了心理博弈元素！

## 🎮 游戏特色

- **心理博弈**：每轮先宣告要出什么，再实际出拳
- **AI 对手**：智能 AI 会分析你的行为模式并制定策略
- **策略欺骗**：你可以撒谎，AI 也会！
- **精美界面**：现代化的网页界面，支持移动端
- **历史记录**：查看每轮的宣告与实际出拳对比

## 🚀 快速开始

### 1. 准备工作

1. 获取 DeveloperWorks API 密钥：
   - 访问 [DeveloperWorks 控制台](https://developerworks.agentlandlab.com)
   - 注册并创建项目
   - 获取 `gameId` 和 `developerToken`

2. 确保你有现代浏览器（支持 ES6 模块）

### 2. 运行游戏

#### 方法一：直接在浏览器中运行

1. 下载所有文件到本地文件夹
2. 使用本地服务器运行（因为需要加载 ES6 模块）：

```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Node.js
npx serve .

# 或使用 PHP
php -S localhost:8000
```

3. 在浏览器中访问 `http://localhost:8000`

#### 方法二：使用 Live Server（推荐）

1. 安装 VS Code 的 Live Server 扩展
2. 右键点击 `index.html`
3. 选择 "Open with Live Server"

### 3. 测试配置（推荐）

在开始游戏前，建议先测试 SDK 是否正常工作：

1. 访问 `test.html` 页面
2. 输入你的 gameId 和 developerToken
3. 点击"测试SDK初始化"
4. 如果成功，再点击"测试AI聊天"
5. 确认一切正常后，开始游戏

### 4. 配置游戏

有两种方式配置游戏：

#### 方式一：使用配置文件（推荐）
1. 打开 `config.js` 文件
2. 填入你的配置信息：
   ```javascript
   export default {
     auth: {
       gameId: '你的游戏ID',           // 🔑 必填
       developerToken: '你的开发者令牌'  // 🔑 可选，测试用
     }
   };
   ```
3. 保存文件，启动游戏即可自动加载配置

#### 方式二：界面输入
1. 在游戏界面中输入你的配置：
   - **游戏ID**：从控制台获取的 gameId
   - **开发者令牌**：用于测试的 developerToken（可选）
   - **玩家昵称**：你的游戏昵称

2. 点击"开始游戏"

> 💡 **提示**：如果 `config.js` 中有配置，会优先使用配置文件中的设置

## 🎯 游戏规则

### 基本流程
1. **宣告阶段**：你先告诉 AI 要出什么（可以撒谎）
2. **AI 回应**：AI 告诉你它的计划（也可能撒谎）
3. **实际出拳**：选择你真正要出的
4. **结果判定**：根据实际出拳判定胜负

### 胜负规则
- 石头 ✊ 克 剪刀 ✌️
- 剪刀 ✌️ 克 布 ✋
- 布 ✋ 克 石头 ✊
- 相同则平局

### 策略要点
- **诚实策略**：宣告与实际一致，建立信任
- **欺骗策略**：宣告与实际不同，迷惑对手
- **心理分析**：观察 AI 的行为模式，制定反制策略

## 🤖 AI 特性

我们的 AI 对手具备以下能力：

- **模式识别**：分析你的宣告与实际出拳的一致性
- **历史分析**：记住最近几轮的游戏历史
- **策略调整**：根据你的行为调整自己的策略
- **随机性平衡**：70% 策略性 + 30% 随机性，保持游戏趣味
- **心理博弈**：会故意误导你，也会分析你的误导

## 🐛 故障排除

### 常见问题

1. **游戏无法启动**
   - 检查 gameId 是否正确
   - 确保网络连接正常
   - 查看浏览器控制台错误信息

2. **AI 回应异常**
   - 检查 API 配额是否充足
   - 尝试刷新页面重新开始

3. **界面显示问题**
   - 确保使用现代浏览器
   - 检查是否通过本地服务器访问

### 调试模式

在配置中启用 `enableDebugLogs: true` 可以在控制台查看详细日志。
